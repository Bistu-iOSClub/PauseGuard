# Architecture Decision Records

记录 PauseGuard 中长期有效且存在真实取舍的架构决策。

## 命名

```text
NNNN-short-title.md
```

## 模板

```markdown
# ADR-NNNN: 决策标题

- **Date:** YYYY-MM-DD
- **Status:** proposed | accepted | deprecated | superseded

## Context

## Decision

## Alternatives

## Consequences

## Verification
```

被替代的 ADR 保留历史，并在原文和新 ADR 中交叉引用。不要为变量命名或普通文件拆分创建 ADR。
