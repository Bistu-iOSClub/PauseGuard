---
name: create-adr
description: Create or update a PauseGuard architecture decision record. Use when a consequential, durable technical choice needs its context, alternatives, and tradeoffs recorded.
---

1. Read `docs/adr/README.md` and relevant code or research.
2. Choose the next four-digit number and save to `docs/adr/NNNN-title-with-dashes.md`.
3. Include title, date, status, context, decision, alternatives, consequences, and follow-up verification.
4. Use `proposed`, `accepted`, `deprecated`, or `superseded` status.
5. Cross-link a superseding ADR and update the superseded record.
6. Do not create ADRs for local naming or routine file organization.
